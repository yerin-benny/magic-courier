# 마법 배달부의 세계일주

초등 6학년 2학기 **분수의 나눗셈** 복습 웹앱.
문제를 풀어 세계 곳곳에 마법 소포를 배달하고, 도착한 나라마다 여권 스탬프를 모은다.

> 만드는 목적은 한 줄이다 — **새로운 배송지에 가고 싶어서 분수의 나눗셈을 한 문제 더 풀게 만드는 것.**
> 게임 요소가 문제 풀이보다 앞서지 않는다.

## 무엇이 들어 있나

- **문제 생성기** — 유형 A~G + 문장제 20맥락. 문제은행이 아니라 생성기라서 반복해도 같은 문제를 외우지 못한다.
  최근 60문항은 다시 나오지 않는다.
- **채점 규칙** — 약분이 덜 된 답은 오답이 아니라 "더 줄일 수 있어요", 가분수와 대분수는 같은 답,
  답이 자연수면 자연수 칸만 채워도 정답.
- **배송·세계일주** — 배송 1건 = 5문제 = 나라 1개 도착. 회차 = 4개국 = 한 차시 분량.
- **여권** — 30개국 × 2권, 대륙별 진행.
- **별빛 상점** — 문제를 풀어 모은 별가루로 빗자루·모자·망토·가방·핀·동물 친구를 산다. 전부 외형 전용.
- **세계지리 둘러보기** — 대륙·대양·적도·본초자오선, 나라별 반구와 위경도, 우리나라에서의 거리와 방향.
  6학년 2학기 사회와 맞물리게 넣었고, **문제로 내지는 않는다.**
- **학교 배송량** — Cloud Functions 가 판정하는 학교 단위 집계 (Firebase 설정이 있을 때만).

## 돌려 보기

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트 313개
npm run build    # dist/ 생성
```

Firebase 설정이 없으면 브라우저 저장(localStorage)만으로 전부 동작한다.
학교 배송량 화면만 안내로 바뀐다. 연결 절차는 [docs/FIREBASE.md](docs/FIREBASE.md).
